Web Wide World V2 - 全新3D高斯泼溅场景体验

Web Wide World V2 版本带来全新的场景浏览体验，基于 3D Gaussian Splatting 技术。

V2 新特性

  • 更流畅的场景切换
  • 优化的移动端体验
  • 新增多个精美3D重建场景
  • 支持自定义场景URL

如何使用

  1. 浏览下方场景列表，选择感兴趣的3D场景
  2. 点击"查看详情"进入沉浸式3D体验
  3. 或在搜索框输入自定义场景URL

技术特点

  • 基于 Three.js 的 WebGL 渲染
  • 支持 3D Gaussian Splatting (3DGS) 格式
  • 响应式设计，支持移动端
